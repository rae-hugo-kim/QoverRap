## 2. 공지예외 적용 주장의 취지

본 출원의 발명은 출원 전에 출원인 자신에 의하여 인터넷 공개 저장소(GitHub)를 통해 공개되었다. 이는 특허법 제30조 제1항 제1호에 규정된 "특허를 받을 수 있는 권리를 가진 자에 의하여 그 발명이 제29조 제1항 각 호의 어느 하나에 해당하게 된 경우"에 해당하므로, 그 공개일부터 12개월 이내에 출원된 본 출원에 대하여 신규성·진보성 판단 시 해당 공개를 선행기술에서 제외할 것을 주장한다.

- **적용 조항**: 특허법 제30조 제1항 제1호
- **공개 유형**: 출원인 자신에 의한 공지(전기통신회선을 통한 공중의 이용 가능)
- **12개월 기한**: 최초 공개일 **2026-04-14** 기준 → **2027-04-14 이전 출원**이어야 적용 가능 (본 출원은 그 이전 출원으로 요건 충족)

## 5. 공개 사실 및 시점의 증명 (증거방법)

### 증거 1 — 저장소 메타데이터 (공개 상태·생성일 증명)
GitHub 저장소 메타데이터 (`docs/patent/evidence/github-repo-metadata.json`):

```json
{
  "createdAt": "2026-04-14T05:21:23Z",
  "isPrivate": false,
  "visibility": "PUBLIC",
  "nameWithOwner": "rae-hugo-kim/QoverRap",
  "url": "https://github.com/rae-hugo-kim/QoverRap",
  "pushedAt": "2026-05-15T09:08:52Z"
}
```
→ 저장소가 2026-04-14에 PUBLIC으로 생성되었고, 2026-05-15까지 공개 push가 이루어졌음을 증명.

### 증거 2 — commit 이력 (공개 시점·연속성 증명)
git commit log 전체 (`docs/patent/evidence/git-commit-log.txt`).

최초 commit:
```
601eb6c | 2026-04-14 14:21:29 +0900 | rae.kim <rae.kim@aipq.kr> | Initial commit
```
→ 각 commit의 일자·작성자(이메일)가 시계열로 기재되어, 발명 내용의 공개 시점과 공개자 동일성을 동시에 증명.

### 증거 3 — Web Archive 영구 캡처 (제3자 보관 시점 증명)
Internet Archive 영구 보존 캡처 (`docs/patent/evidence/web-archive-capture.txt`):

- 캡처 시각: **2026-05-15 06:56:21 UTC (= 2026-05-15 15:56:21 KST)**
- 영구 URL: **`https://web.archive.org/web/20260515065621/https://github.com/rae-hugo-kim/QoverRap`**

→ GitHub의 자체 보존 정책과 독립된 제3자(Internet Archive) 보관 기록으로, 공개 사실과 그 시점을 출원인이 임의로 변경할 수 없는 형태로 증명.

### 증거 4 — GitHub 계정 Security log (생성 이후 비공개 전환 부존재 증명) ★결정적
출원인 GitHub 계정의 Security log (`https://github.com/settings/security-log?q=action%3Arepo.access`)에서 본 저장소에 대한 **`repo.access`(공개/비공개 전환) 이벤트가 0건**임을 확인.

- 본 저장소는 2026-04-14 생성. Security log의 보존 윈도우(90일)는 저장소 전 생애를 포함.
- 그 윈도우 내에 visibility 변경 이벤트가 전무 → 저장소는 **생성 시점(2026-04-14)의 상태(PUBLIC)를 단 한 번도 변경 없이 현재까지 유지**.

→ "생성 때부터 계속 공개였는가"라는 의문을 직접 종결하는 권위적 증거. (캡처본을 `docs/patent/evidence/`에 보관 — §7 첨부 7)

### 증거 5 — GitHub public 활동 이벤트 (제3자 시점, 보조)
GitHub public events API상 본 저장소의 최초 public PushEvent:
```
PushEvent  rae-hugo-kim/QoverRap  2026-04-29T07:59:36Z
```
- 비공개 저장소의 push는 public events 피드에 노출되지 않으므로, 본 이벤트의 존재는 **2026-04-29 시점에 저장소가 PUBLIC이었음을 GitHub 측 기록으로 독립 증명**한다 (Web Archive 05-15 캡처보다 이른 제3자 타임스탬프).

→ 증거 4(생성부터 무변경)와 결합하여, 최초 공개일 2026-04-14 주장을 보강.
